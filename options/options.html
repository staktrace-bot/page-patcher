Page Patcher settings

AI model

Page Patcher sends a condensed outline of the page you're patching (and sometimes a screenshot) to xAI's API, using your own API key. Field values like passwords are never included. Get a key at console.x.ai.

Default is grok-4.7. grok-4.20-0309-non-reasoning is usually faster and cheaper.

Floating button

On Android, add-on buttons are tucked into the menu. The floating button opens Page Patcher in a panel on top of the page.
